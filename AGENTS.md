# Repository guidance

icecheck is a stateless TanStack Start SPA for manual, two-browser WebRTC diagnostics. Preserve the central privacy and deployment property: SDP payloads move between users by copy and paste and are never sent to an application signaling service.

## Working locally

- Use Node.js 24 and npm.
- Run `npm run dev` for the development server (port 4173 by default).
- Run `npm run verify` before handing off code changes.
- Run `npm run test:e2e` for user-flow or browser-lifecycle changes. It starts the development server unless `E2E_BASE_URL` is set. Install Chromium with `npx playwright install chromium` if needed.
- Keep all Playwright output in `.playwright/`.
- Use Conventional Commits and commit directly to `main` unless the task says otherwise.

## Architecture

- Pages live in route folders as `index.tsx`; do not add flat page files.
- Put route-only UI under a hyphen-prefixed folder such as `-components` so TanStack Router ignores it.
- Routes may import public components from `src/modules/icecheck/components`, but not feature hooks or libraries directly.
- Feature modules must never import route-owned code.
- Keep native browser lifecycle code in `*.client.ts` files and load it after hydration.
- Dispose peer connections, channels, tracks, event listeners, intervals, and pending work when the diagnostic unmounts or resets.
- Do not hand-edit `src/routeTree.gen.ts`; it is generated by TanStack Router.
- Keep `/config` and `/health` stateless. Do not add rooms, connection registries, or persistent signaling without an explicit architecture decision.

The detailed boundaries and negotiation sequence are in `docs/architecture.md`. The payload schema and validation rules are in `docs/manual-signaling.md`.

## Product and copy

- Write for developers, but prefer readable labels over internal identifiers in the UI. Exact protocol field names belong in the JSON report and protocol documentation.
- Call the configured strategy “STUN-assisted,” not “STUN only”: host candidates remain enabled and no relay policy is applied.
- State clearly that no TURN server is configured, so a failed direct connection does not prove WebRTC is unavailable.
- Treat payloads and reports as sensitive network metadata. Base64url is encoding, not encryption.
- Preserve accessible names, visible focus styles, keyboard operation, status announcements, and the mobile layout when changing controls.

## Tests and generated output

- `npm run lint` runs ESLint plus import-boundary checks.
- `npm test` builds the production app before running server and codec tests.
- `npm run verify:full` includes the Playwright suite.
- Update user-facing assertions when intentionally changing copy; do not weaken them to make unintended changes pass.
- Never commit `.output`, `.vite`, `.tanstack`, or transient Playwright artifacts.
